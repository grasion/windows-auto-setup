# 블로그 게시용 자료

Windows 자동 설치 도우미 소개 글과 이미지입니다.

| 파일 | 용도 |
|---|---|
| `post.html` | **네이버 블로그 / 티스토리 등에 붙여넣기용** - 브라우저로 열어 글 영역을 복사 → 블로그 글쓰기 화면에 붙여넣기 |
| `post.md` | 마크다운 원고 (티스토리 마크다운 모드, velog, GitHub 등) |
| `images/` | 글에 들어가는 이미지 9장 (순서대로 번호) |

## 이미지 목록

| 파일 | 내용 |
|---|---|
| `00_logo.png` | 프로그램 아이콘 (대표 이미지/썸네일용) |
| `01_main.png` | 메인 화면 |
| `02_settings_registry.png` | 윈도우 초기 설정 목록 + 사용자 레지스트리 |
| `03_winget_panel.png` | 추가 앱 선택 패널 |
| `04_program_editor.png` | 설치 옵션 편집 창 |
| `05_registry_editor.png` | 레지스트리 직접 추가 창 |
| `06_serial_popup.png` | 시리얼 알림 창 |
| `07_progress.png` | 진행 상황 창 |
| `08_coffee.png` | 커피 후원 창 |

## 올리는 방법

1. `post.html` 을 더블클릭해 브라우저로 엽니다.
2. 노란 안내 상자 아래의 글 영역을 드래그해서 복사(Ctrl+C)합니다.
3. 블로그 글쓰기 화면에 붙여넣기(Ctrl+V) 합니다.
4. 이미지가 함께 붙지 않는 블로그(네이버 등)는 `images` 폴더의 사진을 같은 위치에 직접 올립니다.
5. 대표 이미지(썸네일)는 `00_logo.png` 또는 `01_main.png` 를 추천합니다.

> 스크린샷의 설치 파일 경로와 PC 이름은 예시 값입니다.
